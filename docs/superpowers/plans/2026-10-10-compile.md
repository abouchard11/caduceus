# `cad compile` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `cad compile` (profile → cast → USER.md → loadout install) and `cad eval loadout` (paired A/B runs with a pre-registered kill rule), with Jev in exactly two bounded slots.

**Architecture:** Five new stdlib modules (`profile`, `archetypes`, `compile`, `manifest`, `loadout`) plus `jev` (HTTP client), `classify` (domain distribution) and `evalpair` (paired runs). The council gains a believability blend and three ledger columns. Code owns control flow; Jev answers typed questions; nothing a model says picks a lead.

**Tech Stack:** Python ≥ 3.9, stdlib only (`json`, `urllib`, `sqlite3`, `hashlib`, `shutil`, `fnmatch`), pytest. Hermes profiles under `$HERMES_HOME/profiles/<seat>`.

**Spec:** `docs/compile-design.md` (decisions in `docs/DECISIONS.md` 11–24).

## Global Constraints

- `dependencies = []` in pyproject: no third-party imports anywhere.
- `requires-python = ">=3.9"`: no `match`, no `X | Y` types, no `tomllib`.
- Secrets: `TYPESAFE_API_KEY` is read through `config.load_env()`; never printed, never logged, never in a test fixture as a real value.
- Tests run under conftest's isolated `CADUCEUS_HOME` / `HERMES_HOME`; no test touches the real `~/.hermes` or `~/.caduceus`.
- Main stays checked out at `~/projects/caduceus` (launchd runs the editable install). All work is in the `feat/compile` worktree.
- Commit messages: imperative, scoped (`compile: …`, `ledger: …`), no attribution trailers.
- The five existing `seats/<seat>/SOUL.md` files are never modified.
- The operating-contract block in USER.md is byte-identical before and after generation.

## Review Focus

1. A PROFILE.json where a facet appears both at top level and nested under its trait with different numbers: the loader must raise, not silently prefer one. (Task 1 test `test_conflicting_facet_raises`.)
2. A manifest root that does not exist on this machine (plugin cache absent on a stranger's box): scan must skip with a logged line, not crash. (Task 7 test `test_missing_root_skipped`.)
3. A loadout install where a skill directory in the table was removed from disk after the proposal: install must skip and record it, never copy a stale cache or abort the whole seat. (Task 9 test `test_missing_skill_source_skipped`.)
4. `cad eval loadout` interrupted between arm A and arm B (exception in the council): install state must be restored in a `finally`. (Task 10 test `test_pair_restores_state_on_failure`.)
5. A Jev response whose probabilities omit a domain or sum to 0.97: the classifier must renormalise over present keys and never KeyError. (Task 6 test `test_partial_probabilities_renormalised`.)

```python
"""Gap vector: the person as data. PrinciplesYou taxonomy, any instrument."""
from __future__ import annotations
import hashlib, json
from dataclasses import dataclass, field
from pathlib import Path
from typing import Dict, List, Optional

SCHEMA = "caduceus.profile.v1"
DATA = Path(__file__).resolve().parent / "data" / "principlesyou.json"

class ProfileError(ValueError):
    pass

def norm(name: str) -> str:
    return " ".join(name.replace("-", " ").replace("_", " ").lower().split())

def taxonomy() -> Dict[str, List[str]]:
    d = json.loads(DATA.read_text())
    known = {norm(t): [norm(f) for f in fs] for t, fs in d["traits"].items()}
    for i in d["independent"]:
        known[norm(i)] = []
    return known

@dataclass
class Profile:
    raw: dict
    pcts: Dict[str, int]
    confs: Dict[str, float]
    sha256: str
    warnings: List[str] = field(default_factory=list)

    def pct(self, name: str) -> Optional[int]:
        return self.pcts.get(norm(name))
    def confidence(self, name: str) -> float:
        return self.confs.get(norm(name), 1.0)
    @property
    def least_like(self) -> List[str]:
        return list(self.raw.get("archetypes", {}).get("least_like", []))
    @property
    def best_archetype(self) -> str:
        return self.raw.get("archetypes", {}).get("best", "")
    @property
    def person(self) -> dict:
        return self.raw.get("person", {})
    @property
    def notes(self) -> Dict[str, str]:
        return dict(self.raw.get("notes", {}))

def _pct(v, where) -> int:
    if not isinstance(v, (int, float)) or isinstance(v, bool) or not 0 <= v <= 100:
        raise ProfileError(f"{where}: pct must be 0-100, got {v!r}")
    return int(v)

def load(path: Path) -> Profile:
    text = Path(path).read_text()
    raw = json.loads(text)
    if raw.get("schema") != SCHEMA:
        raise ProfileError(f"schema must be {SCHEMA}")
    known = taxonomy()
    all_known = set(known) | {f for fs in known.values() for f in fs}
    pcts: Dict[str, int] = {}; confs: Dict[str, float] = {}; warnings: List[str] = []
    def put(name, pct, conf, where):
        k = norm(name)
        if k in pcts and pcts[k] != pct:
            raise ProfileError(f"{where}: '{name}' given twice with different values")
        pcts[k] = pct; confs[k] = conf
        if k not in all_known:
            warnings.append(f"unknown trait/facet '{name}' (not in PrinciplesYou taxonomy)")
    for name, entry in raw.get("traits", {}).items():
        if not isinstance(entry, dict):
            raise ProfileError(f"traits.{name}: must be an object")
        conf = float(entry.get("confidence", 1.0))
        if not 0.0 <= conf <= 1.0:
            raise ProfileError(f"traits.{name}: confidence must be 0-1")
        if "pct" in entry:
            put(name, _pct(entry["pct"], f"traits.{name}"), conf, f"traits.{name}")
        for fname, fv in entry.get("facets", {}).items():
            put(fname, _pct(fv, f"traits.{name}.facets.{fname}"), conf,
                f"traits.{name}.facets.{fname}")
    return Profile(raw=raw, pcts=pcts, confs=confs,
                   sha256=hashlib.sha256(text.encode()).hexdigest(), warnings=warnings)
```

- [ ] **Step 3: Implement `caduceus/archetypes.py`**

Trigger helpers evaluate against `Profile`; the caller supplies `extra(name)` (the confidence gate in points). Each trigger returns `(fired, margin, reason)` where margin is how many points past the effective threshold the decisive trait sits (≥0 when fired, negative shortfall when not).

```python
from __future__ import annotations
from dataclasses import dataclass
from typing import Callable, List, Tuple
from .config import SEATS
from .profile import Profile

Trig = Tuple[bool, float, str]

def _low(p: Profile, name: str, thr: int, extra: float) -> Trig:
    v = p.pct(name)
    if v is None:
        return (False, -999.0, f"{name} missing")
    eff = thr - extra
    return (v <= eff, eff - v, f"{name} {v} vs ≤{int(eff)}")

def _high(p: Profile, name: str, thr: int, extra: float) -> Trig:
    v = p.pct(name)
    if v is None:
        return (False, -999.0, f"{name} missing")
    eff = thr + extra
    return (v >= eff, v - eff, f"{name} {v} vs ≥{int(eff)}")

def _least(p: Profile, arche: str) -> Trig:
    hit = arche.lower() in [a.lower() for a in p.least_like]
    return (hit, 50.0 if hit else -50.0, f"least-like {arche}" if hit else f"not least-like {arche}")

def _any(*ts: Trig) -> Trig:
    best = max(ts, key=lambda t: t[1])
    return (any(t[0] for t in ts), best[1], best[2])

def _all(*ts: Trig) -> Trig:
    worst = min(ts, key=lambda t: t[1])
    return (all(t[0] for t in ts), worst[1], " and ".join(t[2] for t in ts))

@dataclass
class Archetype:
    key: str; seat: str; display: str; belbin: str; job: str
    trigger: Callable[[Profile, Callable[[str], float]], Trig]
    domains: List[str]; model: str; provider: str; family: str
    soul_template: str = ""

def _seat(name):

    return dict(domains=list(s.domains), model=s.model, provider=s.provider, family=s.family,
                soul_template=f"(hand-written: seats/{name}/SOUL.md)")
```

```python
from __future__ import annotations
import hashlib, json, time
from dataclasses import dataclass, field, asdict
from typing import List
from . import archetypes, config
from .config import Seat
from .models import heterogeneity_warnings
from .profile import Profile

CAST_MIN, CAST_MAX = 4, 6
CONFIDENCE_GATE, GATE_EXTRA = 0.7, 10.0
CAST_SCHEMA = "caduceus.cast.v1"

@dataclass
class CastSeat:
    key: str; seat: str; display: str; fired: bool; margin: float; reason: str

@dataclass
class Cast:
    profile_sha256: str
    seats: List[CastSeat]
    warnings: List[str] = field(default_factory=list)
    generated: str = ""
    @property
    def sha256(self) -> str:
        return hashlib.sha256(json.dumps([s.seat for s in self.seats]).encode()).hexdigest()
    def to_json(self) -> dict:
        return {"schema": CAST_SCHEMA, "profile_sha256": self.profile_sha256,
                "cast_sha256": self.sha256, "generated": self.generated,
                "seats": [asdict(s) for s in self.seats], "warnings": self.warnings}

def seat_for(key: str) -> Seat:
    a = next(x for x in archetypes.LIBRARY if x.key == key)
    if a.seat in config.SEATS:
        return config.SEATS[a.seat]
    return Seat(name=a.seat, display=a.display, role=a.job, model=a.model,
                provider=a.provider, family=a.family, temperature_hint="balanced",
                port=8660 + archetypes.LIBRARY.index(a), domains=list(a.domains))

def cast(p: Profile) -> Cast:
    def extra(name: str) -> float:
        return GATE_EXTRA if p.confidence(name) < CONFIDENCE_GATE else 0.0
    rows: List[CastSeat] = []
    for a in archetypes.LIBRARY:
        fired, margin, reason = a.trigger(p, extra)
        rows.append(CastSeat(a.key, a.seat, a.display, fired, round(margin, 1), reason))
    chosen = [r for r in rows if r.fired]
    if len(chosen) < CAST_MIN:
        fill = sorted((r for r in rows if not r.fired), key=lambda r: -r.margin)
        chosen += fill[:CAST_MIN - len(chosen)]
    if len(chosen) > CAST_MAX:
        chosen = sorted(chosen, key=lambda r: -r.margin)[:CAST_MAX]
    order = {a.key: i for i, a in enumerate(archetypes.LIBRARY)}
    chosen.sort(key=lambda r: order[r.key])
    warns = heterogeneity_warnings([seat_for(r.key) for r in chosen])
    return Cast(profile_sha256=p.sha256, seats=chosen, warnings=list(warns),
                generated=time.strftime("%Y-%m-%dT%H:%M:%S"))
```
